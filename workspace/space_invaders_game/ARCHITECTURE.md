# Architecture Overview: Space Invaders Game

## Overview
This document outlines the architecture of the Space Invaders game built with React.

## Components
1. **App**: The main component that wraps the entire game.
2. **GameBoard**: The container for the game elements.
3. **Player**: The player's spaceship.
4. **Invaders**: The enemies that move across the screen.
5. **Bullets**: The projectiles fired by the player.

## Dependencies
- React for component rendering
- React DOM for DOM manipulation
- CSS for styling
