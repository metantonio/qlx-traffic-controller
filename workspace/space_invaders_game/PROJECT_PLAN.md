Project Name: Space Invaders React Game

### Project Overview
The project aims to create a classic Space Invaders game using React for the frontend and Python with FastAPI for the backend. The game will include basic functionalities such as player movement, shooting, and enemy behavior.

### Components
1. PlayerShip
2. EnemyShips
3. Bullet
4. GameLogic
5. UI

### Initial Setup
1. Create a new React project.
2. Set up a FastAPI backend.
3. Define project structure.

### Next Steps
1. Delegate the development of the PlayerShip component to the frontend developer.
2. Delegate the development of the EnemyShips and Bullet components to the frontend developer.
3. Delegate the implementation of the GameLogic to the backend developer.
4. Delegate the UI development to the frontend developer.
